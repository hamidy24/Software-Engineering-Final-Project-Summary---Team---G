# Interactive Visualization & Coding Platform for Learning Data Structures and Algorithms

## Features
### Algorithm & Data Structure Visualization
- Visual representations of sorting, searching, and tree traversals.
- Visual representations for arrays, linked lists, stacks, queues, trees, and graphs.
- Step-by-step execution controls.
- Play, pause, resume, and speed animation controls.
### Built-in Code Editor & Execution
- Clear coding area with run controls and error messages.
- Secure, isolated code execution engine.
- Dropdown menu for Algorithm Selection.
- Synchronized code execution highlighting visual steps.
### User Management & Content
- Registration, login, and authentication.
- Role-Based Access Control (Student, Teacher, Contributor, Admin).
- Course creation and content management workflows.
- Progress tracking, search functionality, and feedback options.
