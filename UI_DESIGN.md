# User Interface & Experience Design

## Wireframe Specifications
1. **Authentication Portal:** Minimalist, centered card with email/password inputs and role-selection toggles.
2. **Student Dashboard:** Grid layout. Left sidebar for navigation; main pane features radial progress charts; right pane shows "Problem of the Day."
3. **Workspace (The IDE):** 
   - **Left Panel (30%):** Problem description, Big-O metrics, custom input fields.
   - **Center Panel (40%):** Monaco Code Editor with execution buttons.
   - **Right Panel (30%):** Real-time HTML5 Canvas rendering engine.
4. **Admin Moderation Panel:** Data table layout with action buttons (Approve, Reject, View Payload) and expanding rows for detailed feedback entry.
